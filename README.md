# Banking Analysis Using SQL

## Project Overview

This project focuses on analyzing banking data using MySQL. It demonstrates how SQL can be used to manage customer information, analyze account balances, examine banking transactions, and explore loan information.

## Objectives

* Manage customer, account, transaction, branch, and loan data.
* Analyze account balances and transaction amounts.
* Identify high-balance accounts.
* Rank customer loans based on loan amounts.
* Generate reports using SQL joins, subqueries, and views.

## Database Tables

The project includes the following tables:

* Customers
* Accounts
* Transactions
* Branches
* Loans

## SQL Concepts Used

* Database and table creation
* DDL and DML commands
* Primary keys and foreign keys
* Constraints
* INSERT, UPDATE, and SELECT statements
* WHERE, ORDER BY, LIMIT, and DISTINCT
* Aggregate functions: SUM, AVG, MIN, MAX, and COUNT
* String, mathematical, and date functions
* GROUP BY and HAVING
* CASE statements
* Window functions: RANK, DENSE_RANK, ROW_NUMBER, LAG, and LEAD
* INNER JOIN and LEFT JOIN
* Subqueries
* Views

## Key Analysis Areas

1. Customer information management
2. Account balance analysis
3. Transaction reporting
4. Loan amount ranking
5. High-balance account identification
6. Deposit transaction analysis
7. Customer account and transaction reporting

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## Project File

Contains the SQL scripts for creating database tables, inserting sample records, modifying table structures, and performing banking data analysis.

## Conclusion

This project demonstrates practical SQL skills for managing relational databases and generating banking reports. It provides hands-on experience with data retrieval, aggregation, joins, subqueries, window functions, and views.
